# Skill library for Acme Data Co. (fictional)

Acme Data Co. is a 40-person data and AI consultancy. Sales runs discovery
calls, Staffing assigns consultants, Delivery sends weekly client status reports.

## Rules for this repo
- Skill folders are named function-task, lowercase with hyphens (sales-call-recap).
- Every new skill gets: a REGISTRY.md row, a tests/<skill>.md file,
  a guides/<skill>.md how-to, and a CHANGELOG.md entry.
- Skills never take irreversible actions (send, update, delete). They draft.
- Sample data is made up. No real companies or people.
